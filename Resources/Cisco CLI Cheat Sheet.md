## Lesson 6 Notes

- DNS translates domain names into IP addresses.
- An A Record maps a hostname to an IPv4 address.
- Clients must know the IP address of the DNS server to perform name resolution.


## Lesson 4 Notes

| Command                     | Purpose                                |
| --------------------------- | -------------------------------------- |
| `vlan 10`                   | Create VLAN 10                         |
| `name HR`                   | Assign a name to the VLAN              |
| `switchport mode access`    | Configure the port as an access port   |
| `switchport access vlan 10` | Assign the port to VLAN 10             |
| `show vlan brief`           | Display VLANs and their assigned ports |
